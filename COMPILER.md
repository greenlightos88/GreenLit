# GreenLight Compiler

> The compiler is a professional artifact engine. It does not interpret raw intent, approve Canon, or become the author.

## Input

The compiler reads an immutable Canon Snapshot and a typed Compile Context.

It never compiles directly from mutable live project state.

## Profiles and Builders

Compilation profiles define ordered sections and output intent. Each section builder is a pure function of the snapshot and context.

Builders:

- preserve source references;
- emit structured data;
- label generated connective prose;
- surface missing information;
- honour protected overrides;
- avoid inventing facts.

## Provenance

Every factual block retains field-level references to the source object version and, where relevant, source field.

Generated connective prose must remain visibly marked as generated and inferential.

## Protected Overrides

User edits are overlays. Regeneration must preserve both the generated version and any protected creator override. Restoring generated content must remain possible.

## Screenplay Modes

Current screenplay compilation supports mode-aware output such as:

- Preserve;
- Editorial;
- Development;
- Production Draft;
- Submission.

## Production Breakdown

Breakdowns may extract cast, locations, props, time, weather, water, crowds, effects, safety, language, cultural-consultation, and department signals.

These remain recommendations until confirmed by qualified humans.

## Quality Gates

Quality gates evaluate dimensions such as:

- Canon integrity;
- completeness;
- continuity;
- story;
- production;
- cultural review;
- formatting;
- provenance;
- external readiness;
- confidentiality.

Failed gates require correction or an explicit recorded override.

## Output Adapters

Implemented adapters should be listed separately from future targets.

Current repository documentation identifies adapters for PDF, DOCX, Markdown, HTML, JSON, plain text, Fountain, and FDX interchange.

Future targets must never be represented as already complete.

## Delivery

Approved deliverables become frozen document versions. Delivery Rooms point to frozen versions, not mutable drafts.
