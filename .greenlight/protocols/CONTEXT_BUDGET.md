# Context Budget Protocol

## Goal

Preserve reasoning capacity for unresolved decisions and integration rather than repeatedly loading completed history.

## Rules

- Begin with the smallest authoritative reading set.
- Search before broad reading; follow references only when they affect the objective.
- Delegate bounded discovery when it can return a concise evidence map.
- Never inject persistent memory automatically as authority.
- Replace repeated prose with file paths, decision IDs, test names, and concise state summaries.
- Do not retain completed investigative branches in active context after their evidence is persisted.
- Avoid parallel agents whose required context substantially overlaps.
- Prefer a fresh session at milestone or architectural boundaries after durable state is updated.

## Minimum Evidence Map

Before implementation, retain only:

- objective and acceptance conditions;
- governing invariants;
- relevant architecture boundaries;
- exact files and tests involved;
- open decisions and risks;
- approved plan.

## Anti-Patterns

- reading the whole repository without a retrieval hypothesis;
- asking every agent to read every governance file;
- repeating full project summaries in each assignment;
- using agent count as a proxy for quality;
- carrying stale implementation detail after verification and persistence.
